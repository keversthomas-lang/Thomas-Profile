# Thomas Kevers — Professional Portfolio

Personal portfolio for Thomas Kevers: Product, Delivery & Operations.

A responsive, static website with career case studies, an interactive delivery diagram, a downloadable CV and Google Calendar booking links.

## Run locally

No installation or build step is required. From this directory:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000 in your browser.

## Files

- `index.html` — content, sections, navigation and contact links
- `style.css` — layout, typography and responsive styles
- `script.js` — interactive Understand / Align / Deliver diagram
- `thomas-kevers.png` — portrait
- `Thomas_Kevers_CV.pdf` — downloadable CV

## Update

Edit the HTML to change the content or Google Calendar reservation URL. Replace the portrait or PDF using the same filenames to retain the existing links. Typography uses Google Fonts and falls back to system sans-serif fonts.

## Hosting

Upload these files to a static host. The site does not require a server backend, environment variables or API keys. For GitHub Pages, select the `main` branch and the root directory in repository Settings → Pages. Publishing through GitHub Pages is a separate step.

The existing Sites-hosted portfolio is at https://thomas-kevers-portfolio.keversthomas.chatgpt.site/.
